---
title: Component Streaming Status
description: Track granular streaming status for component props, nested objects, and array items
---

The `useTamboStreamStatus` hook provides detailed tracking of streaming status for component props as they're generated by the AI. It supports flat props, nested objects, and arrays with item-level completion tracking.

## Basic Usage

```tsx
import { useTamboStreamStatus } from "@tambo-ai/react";

interface CardProps {
  title: string;
  description: string;
  author: string;
}

export function Card({ title, description, author }: CardProps) {
  const { streamStatus, propStatus } = useTamboStreamStatus<CardProps>();

  return (
    <div>
      <h2 className={propStatus.title?.isStreaming ? "opacity-50" : ""}>
        {title || "Loading..."}
      </h2>
      <p>{description}</p>
      <span>{author}</span>
      
      {streamStatus.isStreaming && <Spinner />}
    </div>
  );
}
```

## PropStatus Fields

Each prop in `propStatus` contains:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `isPending` | `boolean` | No content received yet |
| `isStreaming` | `boolean` | Currently receiving content |
| `isSuccess` | `boolean` | Streaming complete |
| `error` | `Error \| undefined` | Any error that occurred |

## Nested Object Tracking

Track streaming status for nested properties:

```tsx
interface UserCardProps {
  user: {
    name: string;
    email: string;
    profile: {
      bio: string;
      avatar: string;
    };
  };
}

export function UserCard({ user }: UserCardProps) {
  const { propStatus } = useTamboStreamStatus<UserCardProps>();

  // Access nested status
  const userStatus = propStatus.user as PropStatus;
  const profileStatus = userStatus.profile as PropStatus;

  return (
    <div>
      <h2 className={userStatus.name?.isStreaming ? "animate-pulse" : ""}>
        {user.name}
      </h2>
      
      {profileStatus.avatar?.isSuccess ? (
        <img src={user.profile.avatar} alt={user.name} />
      ) : (
        <Skeleton className="w-16 h-16 rounded-full" />
      )}
      
      <p>{user.profile.bio}</p>
    </div>
  );
}
```

## Array Tracking

For array props, `propStatus` includes `completedItems` and `streamingItems`:

```tsx
interface RecipeListProps {
  recipes: Array<{
    name: string;
    ingredients: string[];
  }>;
}

export function RecipeList({ recipes }: RecipeListProps) {
  const { propStatus } = useTamboStreamStatus<RecipeListProps>();

  // Access completed and streaming items
  const completedRecipes = propStatus.recipes?.completedItems ?? [];
  const streamingRecipes = propStatus.recipes?.streamingItems ?? [];

  return (
    <div>
      <h2>Recipes</h2>
      
      {/* Show completed recipes */}
      {completedRecipes.map((recipe, index) => (
        <RecipeCard key={index} recipe={recipe} />
      ))}
      
      {/* Show streaming recipes with loading state */}
      {streamingRecipes.map((recipe, index) => (
        <RecipeCard 
          key={`streaming-${index}`} 
          recipe={recipe} 
          isStreaming 
        />
      ))}
      
      {propStatus.recipes?.isStreaming && (
        <div>Loading more recipes...</div>
      )}
    </div>
  );
}
```

## StreamStatus Fields

The global `streamStatus` object provides overall component status:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `isPending` | `boolean` | No content received, not streaming |
| `isStreaming` | `boolean` | Currently streaming any prop |
| `isSuccess` | `boolean` | All props completed successfully |
| `isError` | `boolean` | An error occurred |
| `streamError` | `Error \| undefined` | The error details |

## Common Patterns

### Loading Skeleton Until Complete

Wait for all props before rendering:

```tsx
export function ProfileCard(props: ProfileProps) {
  const { streamStatus } = useTamboStreamStatus<ProfileProps>();

  if (!streamStatus.isSuccess) {
    return <Skeleton className="w-full h-48" />;
  }

  return <FullProfile {...props} />;
}
```

### Progressive Disclosure

Show content as it arrives:

```tsx
export function Article({ title, content, author }: ArticleProps) {
  const { propStatus } = useTamboStreamStatus<ArticleProps>();

  return (
    <article>
      {propStatus.title?.isSuccess ? (
        <h1>{title}</h1>
      ) : (
        <Skeleton className="h-8 w-3/4" />
      )}
      
      {propStatus.content?.isStreaming && (
        <div className="animate-pulse">
          <p>{content}</p>
        </div>
      )}
      
      {propStatus.content?.isSuccess && <p>{content}</p>}
      
      {propStatus.author?.isSuccess && <Author name={author} />}
    </article>
  );
}
```

### Array with Incremental Display

Show array items as they complete:

```tsx
export function TaskList({ tasks }: TaskListProps) {
  const { propStatus } = useTamboStreamStatus<TaskListProps>();

  const completed = propStatus.tasks?.completedItems ?? [];
  const streaming = propStatus.tasks?.streamingItems ?? [];

  return (
    <div>
      {completed.map((task, i) => (
        <TaskItem key={i} task={task} complete />
      ))}
      
      {streaming.map((task, i) => (
        <TaskItem key={`s-${i}`} task={task} loading />
      ))}
    </div>
  );
}
```

## TypeScript Support

The hook accepts a generic type parameter for full type safety:

```tsx
interface MyProps {
  data: {
    nested: {
      value: string;
    };
  };
}

// Fully typed propStatus
const { propStatus } = useTamboStreamStatus<MyProps>();

// TypeScript knows the shape
const dataStatus = propStatus.data as PropStatus;
const nestedStatus = dataStatus.nested as PropStatus;
```

## Streaming Lifecycle

Props move through these states:

1. **Pending** → No content received yet (`isPending: true`)
2. **Streaming** → Receiving content (`isStreaming: true`)  
3. **Success** → Complete (`isSuccess: true`)

The component's `streamingState` determines when props transition from streaming to success.
